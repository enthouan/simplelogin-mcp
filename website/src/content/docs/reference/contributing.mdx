<Aside type="caution" title="Keep live credentials out of contribution artifacts">
  Never put `SL_API_KEY`, `MCP_AUTH_TOKEN`, authorization headers, or SimpleLogin account data in
  tests, fixtures, logs, screenshots, commits, issues, or pull requests. Keep `.env` untracked.
</Aside>
