The server exposes **{TOOL_CATALOG.length} tools across five focused areas**. This page imports the
project's canonical public catalog for names, summaries, annotations, bounds, and documented output
descriptions. Tests verify its names and annotations against tool registration. Input names,
individual required state, and descriptions, plus each tool's complete usage description, are read
from the definitions registered with the server rather than copied into the website.

“Destructive” follows the MCP annotation and includes writes that can interrupt mail
delivery, not only irreversible deletion. Permanent delete tools also require explicit
confirmation. “Idempotent” identifies tools whose repeated call has the same intended effect;
retry tools marked “Not idempotent” only after checking the first result. Every tool has
`openWorldHint: true` because it communicates with the external SimpleLogin API.

Search by tool name, purpose, or input, or narrow the catalog by category and behavior. Every tool
name is a permanent link you can bookmark or share. The example prompts use placeholder values and
contain no credentials or account data.
