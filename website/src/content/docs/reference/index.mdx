`simplelogin-mcp` is a self-hostable, MIT-licensed open source project. It provides an MCP server
for the SimpleLogin API that runs as a local stdio process or a Streamable HTTP service you host.

<Aside type="note" title="Pre-1.0, with a carefully managed tool surface">
  Tool names, response bounds, MCP annotations, and safety behavior are treated as public contracts.
  Changes to that surface should be documented and tested together.
</Aside>

## Documentation contracts

- The [tool catalog](tools/) is generated from the same catalog and schemas used by the server.
- [API coverage](api-coverage/) records supported, deferred, and intentionally excluded
  SimpleLogin API areas.
- [Client compatibility](../getting-started/compatibility/) records the tested local stdio routes,
  evidence scope, and documentation-reviewed alternatives.

The server catalog is the source of truth for registered tool order, behavior annotations, bounds,
and generated reference content. API coverage is tracked separately so the documentation does not
imply that every SimpleLogin API endpoint is exposed.

Normal tests run without live SimpleLogin credentials. The live smoke test is an explicit, opt-in
workflow and is not required for ordinary first-run verification.
