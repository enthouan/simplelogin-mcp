Self-hosted

Protect your key: SL_API_KEY grants full account control. Any HTTP bind beyond loopback also needs MCP_AUTH_TOKEN.

Docker Compose quick start

git clone https://github.com/enthouan/simplelogin-mcp.git
cd simplelogin-mcp
cp .env.example .env
# Set SL_API_KEY and MCP_AUTH_TOKEN in .env
docker compose up -d
docker compose ps
curl http://localhost:3000/health

Compose listens on 0.0.0.0:3000 inside the container, publishes only to 127.0.0.1 by default, and still requires MCP_AUTH_TOKEN.

Direct Node.js on loopback

corepack enable
pnpm install --frozen-lockfile
pnpm build
TRANSPORT=http HOST=127.0.0.1 PORT=3000 \
  SL_API_KEY=sl-your-key-here pnpm start

Connect to POST http://127.0.0.1:3000/mcp. A direct loopback run does not require MCP_AUTH_TOKEN; any wider bind does.

Desktop client process configuration

{
  "mcpServers": {
    "simplelogin": {
      "command": "node",
      "args": ["/absolute/path/to/simplelogin-mcp/dist/index.js"],
      "env": {
        "TRANSPORT": "stdio",
        "SL_API_KEY": "sl-your-key-here"
      }
    }
  }
}

Run pnpm install --frozen-lockfile && pnpm build first. Stdio does not need MCP_AUTH_TOKEN; keep the client config private because it contains your API key.

SL_API_KEY grants full SimpleLogin account control. Create a dedicated key, never commit it, and revoke it at SimpleLogin if it leaks.

MCP_AUTH_TOKEN protects the HTTP server. It is a separate credential; generate one with openssl rand -hex 32 before using Docker or exposing HTTP beyond loopback.

Useful by design

From alias creation to delivery investigation

The server focuses on repeatable SimpleLogin workflows that fit an MCP conversation, with bounded reads and explicit guards around permanent changes.

  1. 01

    Create and tune aliases

    Find an alias, create a random or custom one, then update routing or enabled state.

    alias_list → alias_create_random → alias_update → alias_set_enabled
  2. 02

    Investigate recent mail

    Walk bounded activity pages to inspect forwards, replies, blocks, and bounces.

    alias_get → alias_activity_list
  3. 03

    Send from an alias

    Create or reuse a reverse alias for a recipient; block before permanently deleting.

    contact_create → contact_set_blocked
  4. 04

    Maintain account routing

    Verify mailboxes, inspect custom domains, and change supported alias settings.

    mailbox_list → custom_domain_list → settings_update

Two secrets, two trust boundaries

Keep account access close. Put exposed HTTP behind TLS.

Default to local

Direct HTTP binds to 127.0.0.1. The server refuses an unauthenticated non-loopback bind unless you deliberately enable the unsafe override.

Authenticate every wider bind

Set MCP_AUTH_TOKEN for LAN or public access. Terminate TLS at a reverse proxy—never send its bearer token over plain HTTP on the internet.

Know what origin checks do

MCP_ALLOWED_ORIGINS permits browser origins for POST /mcp. It is an origin allowlist, not a CORS or authentication configuration.
